# 2단계-2 업체 월말 정산 (정산서·부가세·미수금) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 관리자가 관제 웹 "업체 정산"에서 달을 고르면 업체마다 공급가액·부가세·주유비·청구금액과 입금 체크가 보이고, 업체 정산서를 엑셀로 내려받고, 지난 달까지의 미수금을 본다.

**Architecture:** 금액은 저장하지 않고 DB 함수가 오더에서 그때그때 계산한다(설계 A). 줄 계산은 `billing_lines` 하나, 합계는 그 줄을 모은 `billing_totals` 하나에서만 나오고, 화면·엑셀·입금 체크·미수금이 모두 이 둘만 쓴다. 저장하는 것은 입금 체크 `company_payments`(체크할 때 금액 포함)뿐이다.

**Tech Stack:** Supabase Postgres(마이그레이션, RLS, plpgsql, PGlite 테스트), Next.js 관제 웹(서버 컴포넌트·서버 액션·route handler), `exceljs`, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-2단계-2-업체정산-design.md` (앞 설계: `2026-11-19-2단계-1-기사정산-design.md`)

## Global Constraints

- 정산서 오더 = 그 업체 `payment_method = 'postpaid'` AND `status = 'completed'` AND `completed_at`이 그 달(Asia/Seoul). 요금 + 청구 주유비 = 0원인 오더는 뺀다.
- 주유비 청구 = 업체 `fuel_billing = 'customer'` AND `fuel_payer_postpaid = 'office'` 일 때만 그 오더 `fuel_receipts.amount` 합. 아니면 0. 업체 **지금** 설정을 쓴다.
- 공급가액 = 요금(`fare`) 합. 부가세 = floor(공급가액 × 10 / 100) — 정산서 합계에 한 번. 청구금액 = 공급가액 + 부가세 + 주유비. 모두 원 단위 정수.
- 입금 상태: 체크 줄 있고 금액 같음 = `입금 완료`, 줄 있고 다름 = `금액이 달라졌어요`, 줄 없고 청구금액 > 0 = `미입금`. 청구금액 0이고 체크 줄도 없으면 목록에 안 보임.
- 미수금 = 이번 달(Asia/Seoul) **전** 달만. 미입금이면 청구금액 전부, 체크 뒤 늘었으면 늘어난 차액. 줄었으면 미수금 아님, 화면에 `더 받은 돈 N원`.
- 정산 금액·입금 체크는 **관리자(`is_admin()`)만**. 아니면 `FORBIDDEN`. operator는 메뉴도 안 보임.
- 엑셀 파일 이름 `정산서_<업체이름>_YYYY-MM.xlsx`, 시트 하나, 회사 정보 없음.
- 달 고르기 기본값 = 지난 달(Asia/Seoul).
- 비밀값은 커밋하지 않는다. 서버 적용(`db push`)은 사용자 허락 후, 적용 뒤 `supabase/.applied-migration`을 `20261121000024`로 올린다.
- 사용자 문구는 쉬운 한국어.

## Review Focus

1. **달 경계**: 한국 시간 12/01 00:00 직전(11/30 23:59 KST = 11/30 14:59 UTC) 완료는 11월, 직후는 12월. UTC로 자르면 9시간 어긋남 → Task 1 테스트 `한국 시간 달 경계로 나눈다`.
2. **완료 → 되돌림**: 지금 상태가 완료가 아니면 빠짐 → Task 1 테스트 `완료를 되돌린 오더는 빠진다`.
3. **체크 뒤 금액 변화**: 늘면 차액이 미수금, 줄면 미수금 아님 → Task 2 테스트 `체크 뒤 늘어난 차액만 미수금` / `체크 뒤 줄면 미수금이 아니다`.
4. **operator·기사·고객이 함수나 표를 직접 부름**: 모두 거절, 표는 0줄 → Task 2 테스트 `관리자가 아니면 정산 함수와 입금 표를 못 쓴다`.
5. **업체 이름에 파일 이름에 못 쓰는 글자(`/`, `"`)나 한글**: 엑셀 내려받기 이름이 깨지지 않음 → Task 3 테스트 `파일 이름에서 못 쓰는 글자를 바꾼다`.
